# 2026 Language App

A lightweight browser-based language study app that lets you:

- Add vocabulary cards
- Save cards in `localStorage`
- Practice translations in a quick quiz
- Track score during a study session

## Run locally

Because this app is static HTML/CSS/JS, you can serve it with any local web server.

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.
